# Feedbacks Wall

**Feedbacks Wall** is a simple one-page Node.js application that lets users submit and view feedback in real-time. Built with Express.js, HTML, and CSS, it provides a clean and minimal interface for collecting thoughts, comments, or suggestions.

## Features

- 📝 Submit feedback via a simple form  
- 💬 Display feedback entries on the same page  
- 🧱 Clean, responsive UI with HTML & CSS  
- 🟢 Lightweight backend using Express.js

## Technologies Used

- Node.js
- Express.js
- HTML & CSS
