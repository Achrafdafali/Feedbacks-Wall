# Feedbacks Wall

**Feedbacks Wall** is a simple one-page Node.js application that allows users to submit and view feedback. Built with Express.js and EJS, it renders dynamic content on the server and displays it in a clean, responsive interface.

## Features

- 📝 Submit feedback via a simple form  
- 💬 View submitted feedback displayed dynamically  
- 🖼️ Server-side rendering using EJS templates  
- 🎨 Clean and responsive UI with HTML & CSS  
- ⚙️ Lightweight backend using Express.js

## Technologies Used

- Node.js
- Express.js
- EJS (Embedded JavaScript Templates)
- HTML & CSS
- Optional JSON file for feedback storage or in-memory data
